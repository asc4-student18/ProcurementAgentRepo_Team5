# Request Traceability Table

## Assumptions used for manual tracing
- All four tools are called for every request: check_budget, check_vendor_duplication, check_policy_compliance, assess_risk.
- Manager/director threshold policies are treated as governance findings unless explicitly violating approval requirements in the request context.
- Final recommendation uses priority order: escalate overrides deny, and deny overrides approve.
- For near-threshold governance cases (for example amounts close to director threshold), conservative escalation can be applied.
